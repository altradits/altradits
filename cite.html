How to cite Altradits.

One credit line for the site, the code, and the research.

Credit line

One line covers the site, the code, and the research.

Altradits by Stanley Chege Thuita, Kisumu, Kenya. https://altradits.com. MIT.

Link to a page

  • Link the page itself, with its canonical address. This page is https://altradits.com/cite.
  • Every page carries its own canonical address in its head, so copy the address bar as is.

Cite the code

  • The code lives at github.com/altradits/altradits, MIT, version 0.1.0.
  • A machine readable citation file ships with the repo: CITATION.cff.
  • Name the version you used. Versions change, and a versioned cite stays checkable.

Cite the research

  • Product research, reviewed 5 Nov 2026: https://altradits.com/research.
  • The page lists its evidence and sources. Link it, and link the sources you rely on.

What not to claim

  • Do not invent stats, ranks, traffic, or earnings for this project. None are published.
  • Quote fees as stated: kTown payout fee is 1 percent, covered by the customer on the pay page. Developer API live use costs 0.5 percent, prepaid in sats.
  • The Bitcoin whitepaper lives at bitcoin.org/bitcoin.pdf. Link it there, never a copy.
